# 100 Days of Python - Training Projects

A collection of Python projects developed during the "100 Days of Python" learning journey. Each project demonstrates different programming concepts, from basic scripting to object-oriented game development.

## 📋 Project Overview

| Day | Project | Description | Files |
|-----|---------|-------------|-------|
| 05 | Password Generator | Generate random passwords with customizable character types | 1 |
| 07 | HangMan Game | Classic word guessing game with 6 attempts | 1 |
| 08 | Caesar Cipher | Encryption/decryption using letter shifting | 1 |
| 11 | Blackjack Game | Terminal-based card game (Player vs Dealer) | 4 |
| 15 | Coffee Machine Simulator | Interactive coffee shop with resource management | 5 |
| 17 | Quiz Game | True/False quiz on Science: Computers | 4 |
| 19 | Etch-A-Sketch & Turtle Race | Drawing app and racing game | 2 |
| 20 | Snake Game | Classic snake game with WASD controls | 4 |
| 22 | Pong Game | Two-player paddle game | 5 |

**Total: 31 Python files**

## 🚀 Technologies Used

- **Python 3.x** - Core programming language
- **turtle** - Graphics module for visual games (built-in)
- **random** - Random number generation (built-in)
- **Object-Oriented Programming** - Classes and inheritance

## 🛠️ Running the Projects

### Prerequisites
- Python 3.6 or higher
- No external dependencies required (uses only standard library)

### How to Run

**Simple Scripts:**
```bash
cd "Day 05 - Password Generator"
python "Password Generator.py"
```

**Multi-file Projects:**
```bash
cd "Day 11 - Blackjack game"
python "Blackjack game.py"
```

**Turtle Games:**
```bash
cd "Day 20 - Snake game"
python main.py
```
